🎮 Thunder Night: The Library Escape
📖 Project Description

Thunder Night: The Library Escape is a prototype video game developed as part of the VIDEO GAME CONCEPTION module.
It was created by 3rd year university students to apply concepts of game design, level design, gameplay mechanics, and basic artificial intelligence.

This project represents a working prototype intended for educational purposes. It focuses on atmosphere, exploration, and enemy avoidance rather than complex combat systems.

🎓 Academic Information

Academic Level: 3rd Year Students

Module: VIDEO GAME CONCEPTION

Game Engine: Unity

🕹️ Game Concept

The player is trapped inside a dark university environment during a mysterious night.
To escape, the player must explore different areas, solve puzzles, and avoid enemies while navigating through a tense atmosphere.

The gameplay emphasizes:

Exploration and navigation

Puzzle-based progression

Environmental storytelling

Stealth and avoidance mechanics

🧩 Prototype Content

The current prototype includes the following playable areas:

📚 Main Library

Starting zone of the game

Introduces movement and interaction mechanics

Safe area to learn basic controls

🚇 Underground Tunnels

Maze-like environment connecting areas

Low lighting to increase tension

Introduces enemy encounters

🧪 Laboratory (Lab)

Final area of the prototype

More confined space

Increased danger and pressure on the player

👾 Enemies

The prototype includes only one enemy type:

🧟 Zombie

Slow but persistent movement

Patrols specific areas

Detects the player and initiates a chase

Forces the player to hide or escape

⚠️ No combat system is implemented.

🎮 Gameplay Mechanics

Walking and running

Interaction with objects and puzzles

Enemy detection and chase

Checkpoint and respawn system

Simple UI feedback

▶️ How to Use / Run the Project
Option 1: Run in Unity (Recommended for Development)

Install Unity Hub

Install the Unity version used for the project (recommended version mentioned in the project settings)

Open Unity Hub → Open Project

Select the project folder

Open the main scene

Click Play to test the prototype
